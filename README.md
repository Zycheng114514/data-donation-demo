# Data donation demo

A static demo of the participant side of two open-source data donation tools,
[Port](https://github.com/d3i-infra/data-donation-task) and [DDM](https://github.com/uzh/ddm),
each set up to read ChatGPT exports, plus a read-only copy of DDM's researcher interface.
Everything runs in the browser; nothing is sent to a server.

Open it at <https://zycheng114514.github.io/data-donation-demo/>. Use the synthetic test exports linked on the
first page. Texts written as `[things to be filled: ...]` are placeholders.
