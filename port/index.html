How this works

  1. You request a copy of your ChatGPT data from OpenAI and download the .zip file (instructions below).
  2. You select that file on the next page. The file is opened inside your browser. It is not uploaded.
  3. You see a table of what was extracted. You can search it and delete any rows you do not want to share.
  4. Only if you click "Yes, share for research" are the remaining rows sent to the research team.
How to get your ChatGPT export (draft - check against the current ChatGPT interface before fielding)
  1. Sign in at chatgpt.com in a web browser.
  2. Open your profile menu, then Settings → Data controls → Export data → Confirm export.
  3. OpenAI sends an email with a download link. The link expires, so download the file soon after the email arrives.
  4. Save the .zip file. Do not unzip it.

No export at hand? Use the synthetic test file (no real data): synthetic_chatgpt_export_sharded.zip or synthetic_chatgpt_export_legacy.zip.
