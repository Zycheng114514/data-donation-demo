You can include dynamic data in your question text using template variables:

Donated data: Use {{ data }} to insert data from the linked Blueprint. Access specific items with {{ data.0 }} (first item), {{ data.1 }} (second), etc.

Participant info: Use {{ participant }} to include participant-specific information (e.g., {{ participant.url_parameter }}, {{ participant.donation_info }}). For advanced options and examples, see the "template rendering" section in the documentation.

If linked to a Blueprint, the donated data linked to this Blueprint can be included in the question text. Important: If no donated data is linked to the Blueprint the question will not be shown to a participant (e.g., because no consent was given or no data was extracted).
