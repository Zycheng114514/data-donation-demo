Redirect Configuration

Configure whether your participants are redirected to another web-address after reaching the end of your study (i.e., after reaching the debriefing page)
The redirect address must start with https://; It is possible to pass information to the redirect address by passing variables to URL parameters: https://redirect.me/?participantId={{ participant.public_id }}
